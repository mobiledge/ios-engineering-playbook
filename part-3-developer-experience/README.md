# Part III · Developer Experience

**How should engineers *work*?** · the engineering org

opens with developer pain and ends with a measured improvement to the loop.

This is **Part III** of a four-part book that follows one company, Medley, from a solo prototype to
a full product organization. For the whole arc, see the [Series Roadmap](../README.md).
